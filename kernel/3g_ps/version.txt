		Diagnosis:
		          when 2G SIm that does not block 3G is inserted and networkmode = DUAL, UE will start from searching in 3G.
		          if searched PLMN is found (in our case HPLMN) UE will start registration. as auth procedure fails, UE enters
		          emergency and should try search on 2G.
		          problem was condition that blocked this search: if HPLMN is available (on any RAT)-->dont try.
		          this is wrong as availability of HPLMN should not block any PLMN search if needed for some reason, like in this case.
		          availability of PLMN means we found it on last PLMN search.
		          so, UE did not perform this search as it had this condition and always remained stuck on GSM.
		Resolution Details:
		                   this condition was deleted.
		                   UE now searches 2G right after it receives reject on 3G.
